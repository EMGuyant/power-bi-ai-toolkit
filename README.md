# Power BI’s AI Toolkit

**Master the Art of AI-Assisted Development — Modernizing the Way You Build.**

Welcome to the Power BI’s AI Toolkit repository. This project serves as a central hub for the practical patterns, prompts, and architectural strategies discussed in the Power BI’s AI Toolkit series on [ethanguyant.com](https://ethanguyant.com).

In an era where AI is moving from experimental to essential, this toolkit is designed to help Power BI developers explore AI workflows, learn Power BI AI tools, and get started on their journey to modernize the way they build!

## 🛠 How to Use

1. **Clone or download** this repository to your local machine.
2. **Navigate** to the specific scenario folder you wish to explore.
3. **Open** the provided `.pbix` or `.pbip` file in Power BI Desktop.
4. **Review** the markdown files within each folder to see the specific AI prompts and "Before/After" logic used in that lesson.

## 🔑 Prerequisites

To get the most out of this toolkit, you should:
* Have a basic understanding of Power BI and DAX (Data Analysis Expressions)
* Install Power BI Desktop installed on your computer. You can download it for free from the [official Microsoft website](https://powerbi.microsoft.com/en-us/desktop/).
* Have access to **Copilot for Power BI Desktop** to test the Copilot prompts (posts 01 and 02).
* Have **Claude Desktop** and **Node.js** installed to follow the MCP server walkthrough (post 03). See that folder's prerequisites for details.
* Have the latest version of **Power BI Desktop** installed.
